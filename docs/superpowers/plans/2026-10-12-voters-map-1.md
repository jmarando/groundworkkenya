# Voters map, part 1: the map down to the house — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An organiser goes from the campaign's whole area to one house with the wheel, a pinch or a click; every house in the area is on the map, coloured by the doors knocked and the support found; and the field app finds the house an agent is at anywhere in the area, not just in Kileleshwa.

**Architecture:** One PMTiles file of house outlines per map area (zoom 16 vector tiles, built once from Google Open Buildings by a script), served with the app from `public/tiles/` and read a tile at a time: by MapLibre through a custom protocol, and by the field app to match a GPS fix to a house. A new `house_visits` table, written by `record_door`, records every door knocked at a house; two SQL functions sum it per ward and per house for the colours. The Voters screen becomes a full-screen map whose level follows the zoom, with a panel (a bottom sheet on phones) and a People tab.

**Tech Stack:** TanStack Start/Router, React 19, React Query 5, MapLibre GL 6.11, Supabase (Postgres, RLS), plain `tsx` test scripts and SQL tests. No new npm packages (see Decisions).

**Spec:** `docs/superpowers/specs/2026-10-12-voters-map-design.md` (sections 1, 2 "Finding the house", 4 "Houses", "The campaign's map area" and "Door visits and houses", 6, 7, 8 and part 1 of section 9). Read it before starting.

## Decisions this plan makes

The spec leaves these open, or they had to change once the code was read. Each is small and reversible.

1. **The map area lives on `campaigns.map_area`, not `atlas_settings`.** `atlas_settings` has no row until the candidate or manager picks a home area, its `home_area` is required and points at atlas areas Lovable hasn't loaded yet (the figures migration `20261007100000_atlas_first_counties` is still pending there), and only Groundwork can set a map area, because it needs a house file.
2. **No new npm packages.** The spec names `@mapbox/vector-tile` and `pbf` for the phone's lookup, and part 2 will want `d3-delaunay` and `polygon-clipping`. `bun.lock` is written by Lovable's bot and bun isn't installed here, so a dependency added from this side risks breaking Lovable's build. Reading and writing PMTiles and vector tiles for one layer of polygons is about 400 lines of tested code (Tasks 1 and 2). MapLibre's own reader (already in `node_modules`) checks the tiles in a test.
3. **Constituency outlines wait for part 2.** The ward shapes were simplified one by one, so neighbouring wards' borders don't share points (Embakasi North cancels 5 of its 80 edges), and tracing a constituency's outline from them leaves slivers. At the area level the constituencies are named on the map instead; a click on a name flies to the constituency.
4. **Colour by:** Doors and Support (both over the last 30 days: section 6 has the map colour "the houses visited in 30 days"), plus **2022 vote**, which keeps today's atlas shading (each ward shaded by its constituency's 2022 result for the campaign's race, ahead or behind) until part 4 brings results by polling station. The old "Progress" shading and the ward list "largest gaps first" give way to "Doors first".
5. **A click goes one level down:** on a ward at the area or constituency level, into the ward; on a constituency's name, into the constituency; anywhere inside a ward at the ward level, to street level there; on a house, its card. **The area follows the camera:** when the person moves the map (not when the app flies it), the area becomes the ward or constituency under the map's centre, for the zoom on show.
6. **`house_visits.ward_id` is the person's ward.** Every part 1 visit has a person, and the field app's walk list is the ward the agent chose; part 3 adds the ward for visits with no person.
7. **Agents read the house visits they made** (part 3 adds the houses on their lists). The office (super, candidate, manager, organiser) reads every visit in the campaign.
8. **Door events copied in keep no score, except one:** a person's latest conversation at the door takes their current score, the "last score" the spec says a house takes. Older visits keep none.
9. **Kalonzo's public site keeps its ward question off.** With Nairobi's 85 wards in his workspace, the volunteer form would otherwise ask supporters anywhere in Kenya to pick a Nairobi ward. A presidential campaign's site never lists wards.
10. **The People list's houses come from `people.building_id`**, which the field app already sets; a person found by search flies to their house by decoding its plus code, which needs no new column.

```ts
// Unsigned varints (LEB128), as protobuf and PMTiles store whole numbers: seven
// bits a byte, low bits first. Exact up to 2^53, as JavaScript numbers are.

/** Appends n to out. */
export function writeVarint(out: number[], n: number): void {
  let v = n;
  while (v >= 128) {
    out.push((v % 128) | 128);
    v = Math.floor(v / 128);
  }
  out.push(v);
}

/** The varint at at.pos, moving at.pos past it. */
export function readVarint(b: Uint8Array, at: { pos: number }): number {
  let n = 0;
  let scale = 1;
  for (;;) {
    const byte = b[at.pos++];
    if (byte === undefined) throw new Error("A number runs past the end of the data.");
    n += (byte & 127) * scale;
    if (byte < 128) return n;
    scale *= 128;
  }
}
```

```ts
// PMTiles v3 (https://github.com/protomaps/PMTiles/blob/main/spec/v3/spec.md):
// a whole map's tiles in one file, read a tile at a time with HTTP range
// requests, so a static host can serve it. This writes the house files
// (scripts/geo/house-tiles.ts) and reads them in the browser. It holds only
// what they use: one root directory and no leaf directories, gzip for the
// directory, the metadata and the tiles, and vector tiles. Pure apart from the
// gzip and the reading handed in, so it runs the same in tests and browsers.

import { readVarint, writeVarint } from "@/lib/varint";

/** Where a tile's bytes are in the tile data. A run length of 0 marks a leaf directory. */
export type Entry = { tileId: number; offset: number; length: number; runLength: number };

export type Header = {
  rootOffset: number;
  rootLength: number;
  tileDataOffset: number;
  tileCount: number;
  minZoom: number;
  maxZoom: number;
  /** West, south, east, north, in degrees. */
  bounds: [number, number, number, number];
};

/** A tile to write, not yet compressed. */
export type TileIn = { z: number; x: number; y: number; data: Uint8Array };

export type ArchiveInfo = {
  minZoom: number;
  maxZoom: number;
  bounds: [number, number, number, number];
  /** Longitude, latitude and zoom to open at. */
  center: [number, number, number];
  metadata: Record<string, unknown>;
};

export type Archive = {
  header: Header;
  /** The tile's bytes, uncompressed; null when the file has no such tile. */
  getTile(z: number, x: number, y: number): Promise<Uint8Array | null>;
};

/** Reads length bytes from offset; fewer when the file ends first. */
export type ReadRange = (offset: number, length: number) => Promise<Uint8Array>;

const HEADER_BYTES = 127;
/** The header and root directory are in the first 16 KiB, so one request reads both. */
const FIRST_READ = 16_384;
const GZIP = 2;
const MVT = 1;
const U32 = 2 ** 32;

/** A tile's place along the Hilbert curve, after every tile of the zooms below it. */
export function zxyToTileId(z: number, x: number, y: number): number {
  if (z > 26) throw new Error("Zoom past 26 is beyond whole-number precision.");
  const n = 2 ** z;
  if (!Number.isInteger(x) || !Number.isInteger(y) || x < 0 || y < 0 || x >= n || y >= n)
    throw new Error(`There is no tile ${z}/${x}/${y}.`);
  let tx = x;
  let ty = y;
  let d = 0;
  for (let s = n / 2; s >= 1; s /= 2) {
    const rx = (tx & s) > 0 ? 1 : 0;
    const ry = (ty & s) > 0 ? 1 : 0;
    d += s * s * ((3 * rx) ^ ry);
    if (ry === 0) {
      if (rx === 1) {
        tx = n - 1 - tx;
        ty = n - 1 - ty;
      }
      [tx, ty] = [ty, tx];
    }
  }
  return (4 ** z - 1) / 3 + d;
}

export function serializeDirectory(entries: Entry[]): Uint8Array {
  const out: number[] = [];
  writeVarint(out, entries.length);
  let last = 0;
  for (const e of entries) {
    writeVarint(out, e.tileId - last);
    last = e.tileId;
  }
  for (const e of entries) writeVarint(out, e.runLength);
  for (const e of entries) writeVarint(out, e.length);
  entries.forEach((e, i) => {
    const prev = entries[i - 1];
    // 0 means "straight after the previous tile", which most are.
    writeVarint(out, prev && e.offset === prev.offset + prev.length ? 0 : e.offset + 1);
  });
  return Uint8Array.from(out);
}

export function parseDirectory(b: Uint8Array): Entry[] {
  const at = { pos: 0 };
  const count = readVarint(b, at);
  const entries: Entry[] = [];
  let id = 0;
  for (let i = 0; i < count; i++) {
    id += readVarint(b, at);
    entries.push({ tileId: id, offset: 0, length: 0, runLength: 0 });
  }
  for (const e of entries) e.runLength = readVarint(b, at);
  for (const e of entries) e.length = readVarint(b, at);
  entries.forEach((e, i) => {
    const v = readVarint(b, at);
    const prev = entries[i - 1];
    e.offset = v === 0 && prev ? prev.offset + prev.length : v - 1;
  });
  return entries;
}

/** The entry for a tile, by binary search, as the spec has it; null when there is none. */
export function findEntry(entries: Entry[], tileId: number): Entry | null {
  let lo = 0;
  let hi = entries.length - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    const e = entries[mid]!;
    if (tileId > e.tileId) lo = mid + 1;
    else if (tileId < e.tileId) hi = mid - 1;
    else return e;
  }
  // A leaf directory covers the ids after its own; a run of one tile repeated covers its run.
  const before = entries[hi];
  if (before && (before.runLength === 0 || tileId - before.tileId < before.runLength)) return before;
  return null;
}

function setU64(v: DataView, at: number, n: number): void {
  v.setUint32(at, n % U32, true);
  v.setUint32(at + 4, Math.floor(n / U32), true);
}

function getU64(v: DataView, at: number): number {
  return v.getUint32(at, true) + v.getUint32(at + 4, true) * U32;
}

/** One file holding every tile, in tile-id order. Throws if the directory won't fit the first read. */
export function writeArchive(
  tiles: TileIn[],
  info: ArchiveInfo,
  gzip: (b: Uint8Array) => Uint8Array,
): Uint8Array {
  const sorted = tiles
    .map((t) => ({ id: zxyToTileId(t.z, t.x, t.y), data: gzip(t.data) }))
    .sort((a, b) => a.id - b.id);
  const entries: Entry[] = [];
  let tileBytes = 0;
  for (const t of sorted) {
    if (entries[entries.length - 1]?.tileId === t.id) throw new Error("Two tiles at one place.");
    entries.push({ tileId: t.id, offset: tileBytes, length: t.data.length, runLength: 1 });
    tileBytes += t.data.length;
  }
  const root = gzip(serializeDirectory(entries));
  if (HEADER_BYTES + root.length > FIRST_READ)
    throw new Error(`Too many tiles for one directory (${entries.length}): split the area.`);
  const metadata = gzip(new TextEncoder().encode(JSON.stringify(info.metadata)));
  const rootOffset = HEADER_BYTES;
  const metadataOffset = rootOffset + root.length;
  const tileDataOffset = metadataOffset + metadata.length;

  const out = new Uint8Array(tileDataOffset + tileBytes);
  const v = new DataView(out.buffer);
  out.set(new TextEncoder().encode("PMTiles"), 0);
  out[7] = 3;
  setU64(v, 8, rootOffset);
  setU64(v, 16, root.length);
  setU64(v, 24, metadataOffset);
  setU64(v, 32, metadata.length);
  setU64(v, 40, tileDataOffset); // no leaf directories: an empty section
  setU64(v, 48, 0);
  setU64(v, 56, tileDataOffset);
  setU64(v, 64, tileBytes);
  setU64(v, 72, entries.length); // tiles addressed
  setU64(v, 80, entries.length); // directory entries
  setU64(v, 88, entries.length); // distinct tiles
  out[96] = 1; // clustered: tiles in id order
  out[97] = GZIP; // directory and metadata
  out[98] = GZIP; // tiles
  out[99] = MVT;
  out[100] = info.minZoom;
  out[101] = info.maxZoom;
  const e7 = (deg: number) => Math.round(deg * 1e7);
  const [west, south, east, north] = info.bounds;
  v.setInt32(102, e7(west), true);
  v.setInt32(106, e7(south), true);
  v.setInt32(110, e7(east), true);
  v.setInt32(114, e7(north), true);
  const [lng, lat, zoom] = info.center;
  out[118] = zoom;
  v.setInt32(119, e7(lng), true);
  v.setInt32(123, e7(lat), true);
  out.set(root, rootOffset);
  out.set(metadata, metadataOffset);
  let at = tileDataOffset;
  for (const t of sorted) {
    out.set(t.data, at);
    at += t.data.length;
  }
  return out;
}

export function readHeader(b: Uint8Array): Header {
  if (
    b.length < HEADER_BYTES ||
    new TextDecoder().decode(b.subarray(0, 7)) !== "PMTiles" ||
    b[7] !== 3
  )
    throw new Error("Not a PMTiles v3 file.");
  if (b[97] !== GZIP || b[98] !== GZIP || b[99] !== MVT)
    throw new Error("Only gzipped vector tiles are read here.");
  const v = new DataView(b.buffer, b.byteOffset, b.byteLength);
  if (getU64(v, 48) > 0) throw new Error("Leaf directories aren't read here.");
  const deg = (at: number) => v.getInt32(at, true) / 1e7;
  return {
    rootOffset: getU64(v, 8),
    rootLength: getU64(v, 16),
    tileDataOffset: getU64(v, 56),
    tileCount: getU64(v, 72),
    minZoom: b[100]!,
    maxZoom: b[101]!,
    bounds: [deg(102), deg(106), deg(110), deg(114)],
  };
}

/** An archive read through `read`: the header and directory once, then a tile per call. */
export async function openArchive(
  read: ReadRange,
  unzip: (b: Uint8Array) => Promise<Uint8Array>,
): Promise<Archive> {
  const first = await read(0, FIRST_READ);
  const header = readHeader(first);
  const rootEnd = header.rootOffset + header.rootLength;
  if (rootEnd > first.length) throw new Error("The directory isn't where the header says.");
  const entries = parseDirectory(await unzip(first.subarray(header.rootOffset, rootEnd)));
  return {
    header,
    async getTile(z, x, y) {
      if (z < header.minZoom || z > header.maxZoom) return null;
      const n = 2 ** z;
      if (!Number.isInteger(x) || !Number.isInteger(y) || x < 0 || y < 0 || x >= n || y >= n)
        return null;
      const e = findEntry(entries, zxyToTileId(z, x, y));
      if (!e) return null;
      if (e.runLength === 0) throw new Error("Leaf directories aren't read here.");
      return unzip(await read(header.tileDataOffset + e.offset, e.length));
    },
  };
}

/** gzip undone with the platform's own streams, in browsers and Node alike. */
export async function gunzip(b: Uint8Array): Promise<Uint8Array> {
  const stream = new Blob([new Uint8Array(b)]).stream().pipeThrough(new DecompressionStream("gzip"));
  return new Uint8Array(await new Response(stream).arrayBuffer());
}
```

```ts
/** The area inside a closed ring, in square metres (flat: well under 1% off for a house). */
export function ringAreaM2(ring: Ring): number {
  const origin = ring[0];
  if (!origin) return 0;
  let twice = 0;
  for (let i = 0; i < ring.length - 1; i++) {
    const [x1, y1] = toLocalM(ring[i]!, origin);
    const [x2, y2] = toLocalM(ring[i + 1]!, origin);
    twice += x1 * y2 - x2 * y1;
  }
  return Math.abs(twice) / 2;
}
```

```ts
// Plus codes (Open Location Code, https://github.com/google/open-location-code):
// each house in the house files is named by the plus code of its centre, which
// also says where it is, to about 3 metres. Pure.

import type { LngLat } from "@/lib/geo";

const DIGITS = "23456789CFGHJMPQRVWX";

/** A full plus code as Open Buildings gives each house: 8 digits, "+", then 2 to 7. */
export const PLUS_CODE = /^[23456789CFGHJMPQRVWX]{8}\+[23456789CFGHJMPQRVWX]{2,7}$/;

/** The centre of the area a full plus code names; null if it isn't one. */
export function plusCodeCentre(code: string): LngLat | null {
  const c = code.trim().toUpperCase();
  if (!PLUS_CODE.test(c)) return null;
  const d = c.replace("+", "");
  // Five pairs of latitude and longitude digits, each 20 times finer than the last.
  let lat = -90;
  let lng = -180;
  let res = 20;
  for (let i = 0; i < 10; i += 2) {
    lat += DIGITS.indexOf(d[i]!) * res;
    lng += DIGITS.indexOf(d[i + 1]!) * res;
    if (i < 8) res /= 20;
  }
  // Then a 5-row, 4-column grid per digit.
  let latRes = res;
  let lngRes = res;
  for (const ch of d.slice(10)) {
    latRes /= 5;
    lngRes /= 4;
    const v = DIGITS.indexOf(ch);
    lat += Math.floor(v / 4) * latRes;
    lng += (v % 4) * lngRes;
  }
  return [lng + lngRes / 2, lat + latRes / 2];
}
```

```ts
// The house layer of the map's tiles: each house's outline and plus code, at
// zoom 16 only, as Mapbox Vector Tiles
// (https://github.com/mapbox/vector-tile-spec/tree/master/2.1), 1,024 units
// across. The house script writes them; MapLibre draws them, stretching the
// zoom-16 tiles up to 20; and the field app reads the tiles around a phone to
// find the house it is at. A house that crosses a tile edge is written whole
// into each tile it touches, and each tile draws only its own part. Pure.

import { ringAreaM2, ringCentre, type Building, type LngLat, type Ring } from "@/lib/geo";
import { readVarint, writeVarint } from "@/lib/varint";

export const HOUSE_ZOOM = 16;
export const EXTENT = 1024;
export const LAYER = "buildings";

const WORLD = 2 ** HOUSE_ZOOM;
const RAD = Math.PI / 180;
const POLYGON = 3;
const MOVE_TO = 1;
const LINE_TO = 2;
const CLOSE_PATH = 7;
const UTF8_OUT = new TextEncoder();
const UTF8_IN = new TextDecoder();

/** A point on the zoom-16 grid, in tiles: 0 to 65,536 across, y down. */
export type TilePoint = [number, number];

export function toTileSpace([lng, lat]: LngLat): TilePoint {
  const s = Math.sin(lat * RAD);
  return [((lng + 180) / 360) * WORLD, (0.5 - Math.log((1 + s) / (1 - s)) / (4 * Math.PI)) * WORLD];
}

export function fromTileSpace([x, y]: TilePoint): LngLat {
  const n = Math.PI - (2 * Math.PI * y) / WORLD;
  return [(x / WORLD) * 360 - 180, Math.atan(Math.sinh(n)) / RAD];
}

/** A house as the tiles keep it: whole grid units (EXTENT to a tile), rings not closed. */

/** Twice the signed area: positive when the ring turns clockwise on screen (y down). */
function area2(r: [number, number][]): number {
  let a = 0;
  for (let i = 0, j = r.length - 1; i < r.length; j = i++)
    a += r[j]![0] * r[i]![1] - r[i]![0] * r[j]![1];
  return a;
}

/** A house's GeoJSON rings on the tile grid; null when nothing of its outline is left at this scale. */
export function toTileHouse(pc: string, rings: Ring[]): TileHouse | null {
  const out: [number, number][][] = [];
  for (const [i, ring] of rings.entries()) {
    const pts: [number, number][] = [];
    for (const p of ring) {
      const [x, y] = toTileSpace(p);
      const q: [number, number] = [Math.round(x * EXTENT), Math.round(y * EXTENT)];
      const last = pts[pts.length - 1];
      if (!last || last[0] !== q[0] || last[1] !== q[1]) pts.push(q);
    }
    // GeoJSON repeats the first point at the end; the tile format closes rings itself.
    const first = pts[0];
    const end = pts[pts.length - 1];
    if (pts.length > 1 && first && end && first[0] === end[0] && first[1] === end[1]) pts.pop();
    if (pts.length >= 3 && area2(pts) !== 0) out.push(pts);
    else if (i === 0) return null;
  }
  return out.length ? { pc, rings: out } : null;
}

/** The zoom-16 tiles a house touches. */
export function tilesOf(h: TileHouse): { x: number; y: number }[] {
  let minX = Infinity;
  let minY = Infinity;
  let maxX = -Infinity;
  let maxY = -Infinity;
  for (const [x, y] of h.rings[0] ?? []) {
    minX = Math.min(minX, x);
    minY = Math.min(minY, y);
    maxX = Math.max(maxX, x);
    maxY = Math.max(maxY, y);
  }
  const out: { x: number; y: number }[] = [];
  for (let x = Math.floor(minX / EXTENT); x <= Math.floor(maxX / EXTENT); x++)
    for (let y = Math.floor(minY / EXTENT); y <= Math.floor(maxY / EXTENT); y++) out.push({ x, y });
  return out;
}

/** Just enough protobuf to write a vector tile. */
class Writer {
  private bytes: number[] = [];

  varint(field: number, n: number): this {
    writeVarint(this.bytes, field * 8);
    writeVarint(this.bytes, n);
    return this;
  }

  message(field: number, body: Uint8Array): this {
    writeVarint(this.bytes, field * 8 + 2);
    writeVarint(this.bytes, body.length);
    for (const b of body) this.bytes.push(b);
    return this;
  }

  text(field: number, s: string): this {
    return this.message(field, UTF8_OUT.encode(s));
  }

  packed(field: number, ns: number[]): this {
    const body: number[] = [];
    for (const n of ns) writeVarint(body, n);
    return this.message(field, Uint8Array.from(body));
  }

  finish(): Uint8Array {
    return Uint8Array.from(this.bytes);
  }
}

const command = (id: number, count: number) => (id & 7) | (count << 3);
const zigzag = (n: number) => (n << 1) ^ (n >> 31);
const unzigzag = (n: number) => (n >>> 1) ^ -(n & 1);

/** Drawing commands for a house in the tile whose corner is (ox, oy) on the grid. */
function geometry(h: TileHouse, ox: number, oy: number): number[] {
  const out: number[] = [];
  let cx = 0;
  let cy = 0;
  h.rings.forEach((ring, i) => {
    // The outline turns clockwise on screen, its holes the other way.
    const pts = area2(ring) > 0 === (i === 0) ? ring : [...ring].reverse();
    pts.forEach(([gx, gy], k) => {
      if (k === 0) out.push(command(MOVE_TO, 1));
      if (k === 1) out.push(command(LINE_TO, pts.length - 1));
      out.push(zigzag(gx - ox - cx), zigzag(gy - oy - cy));
      cx = gx - ox;
      cy = gy - oy;
    });
    out.push(command(CLOSE_PATH, 1));
  });
  return out;
}

/** One tile of houses, as a vector tile with one layer, "buildings". */
export function encodeTile(x: number, y: number, houses: TileHouse[]): Uint8Array {
  const layer = new Writer().varint(15, 2).text(1, LAYER);
  houses.forEach((h, i) => {
    layer.message(
      2,
      new Writer()
        .packed(2, [0, i])
        .varint(3, POLYGON)
        .packed(4, geometry(h, x * EXTENT, y * EXTENT))
        .finish(),
    );
  });
  layer.text(3, "pc");
  for (const h of houses) layer.message(4, new Writer().text(1, h.pc).finish());
  layer.varint(5, EXTENT);
  return new Writer().message(3, layer.finish()).finish();
}

/** Just enough protobuf to read one back. */
class Reader {
  private readonly b: Uint8Array;
  private readonly at = { pos: 0 };

  constructor(b: Uint8Array) {
    this.b = b;
  }

  get more(): boolean {
    return this.at.pos < this.b.length;
  }

  varint(): number {
    return readVarint(this.b, this.at);
  }

  key(): { field: number; wire: number } {
    const k = this.varint();
    return { field: Math.floor(k / 8), wire: k % 8 };
  }

  bytes(): Uint8Array {
    const n = this.varint();
    const s = this.b.subarray(this.at.pos, this.at.pos + n);
    this.at.pos += n;
    return s;
  }

  skip(wire: number): void {
    if (wire === 0) this.varint();
    else if (wire === 2) this.at.pos += this.varint();
    else if (wire === 1) this.at.pos += 8;
    else if (wire === 5) this.at.pos += 4;
    else throw new Error(`Not a vector tile (wire type ${wire}).`);
  }
}

function packed(b: Uint8Array): number[] {
  const r = new Reader(b);
  const out: number[] = [];
  while (r.more) out.push(r.varint());
  return out;
}

type RawFeature = { tags: number[]; type: number; geometry: number[] };
type RawLayer = {
  name: string;
  extent: number;
  keys: string[];
  values: (string | null)[];
  features: RawFeature[];
};

function readFeature(b: Uint8Array): RawFeature {
  const r = new Reader(b);
  const f: RawFeature = { tags: [], type: 0, geometry: [] };
  while (r.more) {
    const { field, wire } = r.key();
    if (field === 2 && wire === 2) f.tags = packed(r.bytes());
    else if (field === 3 && wire === 0) f.type = r.varint();
    else if (field === 4 && wire === 2) f.geometry = packed(r.bytes());
    else r.skip(wire);
  }
  return f;
}

/** A Value's string; null for numbers and the rest. */
function readText(b: Uint8Array): string | null {
  const r = new Reader(b);
  let s: string | null = null;
  while (r.more) {
    const { field, wire } = r.key();
    if (field === 1 && wire === 2) s = UTF8_IN.decode(r.bytes());
    else r.skip(wire);
  }
  return s;
}

function readLayer(b: Uint8Array): RawLayer {
  const r = new Reader(b);
  const layer: RawLayer = { name: "", extent: 4096, keys: [], values: [], features: [] };
  while (r.more) {
    const { field, wire } = r.key();
    if (field === 1 && wire === 2) layer.name = UTF8_IN.decode(r.bytes());
    else if (field === 2 && wire === 2) layer.features.push(readFeature(r.bytes()));
    else if (field === 3 && wire === 2) layer.keys.push(UTF8_IN.decode(r.bytes()));
    else if (field === 4 && wire === 2) layer.values.push(readText(r.bytes()));
    else if (field === 5 && wire === 0) layer.extent = r.varint();
    else r.skip(wire);
  }
  return layer;
}

/** Drawing commands back to rings, in the tile's own units. */
function ringsOf(g: number[]): [number, number][][] {
  const rings: [number, number][][] = [];
  let ring: [number, number][] = [];
  let x = 0;
  let y = 0;
  let i = 0;
  while (i < g.length) {
    const c = g[i++]!;
    const id = c & 7;
    if (id === CLOSE_PATH) {
      if (ring.length >= 3) rings.push(ring);
      ring = [];
      continue;
    }
    for (let k = 0; k < c >> 3; k++) {
      if (i + 1 >= g.length) return rings;
      x += unzigzag(g[i++]!);
      y += unzigzag(g[i++]!);
      if (id === MOVE_TO) ring = [[x, y]];
      else ring.push([x, y]);
    }
  }
  return rings;
}

const closed = (r: LngLat[]): LngLat[] => (r.length ? [...r, r[0]!] : r);

function layerHouses(layer: RawLayer, x: number, y: number): Building[] {
  const pcKey = layer.keys.indexOf("pc");
  const out: Building[] = [];
  for (const f of layer.features) {
    if (f.type !== POLYGON) continue;
    let pc: string | null = null;
    for (let i = 0; i + 1 < f.tags.length; i += 2)
      if (f.tags[i] === pcKey) pc = layer.values[f.tags[i + 1]!] ?? null;
    const local = ringsOf(f.geometry);
    const first = local[0];
    if (!pc || !first) continue;
    // The first ring's turn marks an outline; rings turning the other way are its holes.
    const outward = area2(first) > 0;
    const rings = [first];
    for (const r of local.slice(1)) {
      if (area2(r) > 0 === outward) break; // a second outline: a house here is one outline
      rings.push(r);
    }
    const geo = rings.map((r) =>
      closed(r.map(([lx, ly]) => fromTileSpace([x + lx / layer.extent, y + ly / layer.extent]))),
    );
    const outline = geo[0]!;
    const holes = geo.slice(1).reduce((s, h) => s + ringAreaM2(h), 0);
    out.push({
      id: pc,
      rings: geo,
      centre: ringCentre(outline),
      area: Math.round(ringAreaM2(outline) - holes),
    });
  }
  return out;
}

/** The houses in one zoom-16 tile, as outlines with their plus codes. */
export function decodeTile(x: number, y: number, bytes: Uint8Array): Building[] {
  const tile = new Reader(bytes);
  while (tile.more) {
    const { field, wire } = tile.key();
    if (field === 3 && wire === 2) {
      const layer = readLayer(tile.bytes());
      if (layer.name === LAYER) return layerHouses(layer, x, y);
    } else tile.skip(wire);
  }
  return [];
}

/** The zoom-16 tiles within radiusM of a point. */
export function tilesAround(p: LngLat, radiusM: number): { x: number; y: number }[] {
  const dLat = radiusM / 111_320;
  const dLng = dLat / Math.max(Math.cos(p[1] * RAD), 0.01);
  const [x0, y0] = toTileSpace([p[0] - dLng, p[1] + dLat]);
  const [x1, y1] = toTileSpace([p[0] + dLng, p[1] - dLat]);
  const out: { x: number; y: number }[] = [];
  for (let x = Math.floor(x0); x <= Math.floor(x1); x++)
    for (let y = Math.floor(y0); y <= Math.floor(y1); y++) out.push({ x, y });
  return out;
}

/** Houses from several tiles, each once: a house on a tile edge is in both. */
export function mergeHouses(lists: Building[][]): Building[] {
  const seen = new Map<string, Building>();
  for (const list of lists) for (const b of list) if (!seen.has(b.id)) seen.set(b.id, b);
  return [...seen.values()];
}
```

```ts
/** A CSV line's fields: a quoted field keeps its commas, and "" inside one is a quote. */
export function splitCsv(line: string): string[] {
  const out: string[] = [];
  let cur = "";
  let quoted = false;
  for (let i = 0; i < line.length; i++) {
    const ch = line[i]!;
    if (quoted) {
      if (ch !== '"') cur += ch;
      else if (line[i + 1] === '"') {
        cur += '"';
        i++;
      } else quoted = false;
    } else if (ch === '"') quoted = true;
    else if (ch === ",") {
      out.push(cur);
      cur = "";
    } else cur += ch;
  }
  out.push(cur);
  return out;
}

/** The latitude and longitude that start every row, read without splitting the rest. */
export function quickPosition(line: string): LngLat | null {
  const a = line.indexOf(",");
  const b = line.indexOf(",", a + 1);
  if (a <= 0 || b <= a + 1) return null;
  const lat = Number(line.slice(0, a));
  const lng = Number(line.slice(a + 1, b));
  return Number.isFinite(lat) && Number.isFinite(lng) ? [lng, lat] : null;
}

export function parseRow(line: string): Row | null {
  const f = splitCsv(line);
  if (f.length !== 6) return null;
  const lat = Number(f[0]);
  const lng = Number(f[1]);
  const confidence = Number(f[3]);
  if (![lat, lng, confidence].every(Number.isFinite)) return null;
  return { lat, lng, confidence, wkt: f[4]!, pc: f[5]!.trim() };
}

/** POLYGON((x y, ...), (x y, ...)): the outline, then any holes (courtyards). */
export function parseWkt(wkt: string): Ring[] | null {
  if (!/^\s*POLYGON\b/i.test(wkt)) return null;
  const rings: Ring[] = [];
  for (const m of wkt.matchAll(/\(([^()]+)\)/g)) {
    const ring: Ring = [];
    for (const pair of m[1]!.split(",")) {
      const [x, y] = pair.trim().split(/\s+/).map(Number);
      if (!Number.isFinite(x) || !Number.isFinite(y)) return null;
      ring.push([x!, y!]);
    }
    if (ring.length >= 4) rings.push(ring);
  }
  return rings.length ? rings : null;
}

export type Collected = {
  houses: TileHouse[];
  perWard: Record<string, number>;
  seen: Set<string>;
  lowConfidence: number;
};

export const emptyCollected = (): Collected => ({
  houses: [],
  perWard: {},
  seen: new Set(),
  lowConfidence: 0,
});

/** Keeps the row's house when it is in one of the wards. */
export function collect(wards: WardShape[], box: Box, row: Row, into: Collected): void {
  const p: LngLat = [row.lng, row.lat];
  if (!inBox(p, box)) return;
  const ward = wardAt(p, wards);
  if (!ward) return;
  if (row.confidence < MIN_CONFIDENCE) {
    into.lowConfidence += 1;
    return;
  }
  if (!BUILDING_ID.test(row.pc) || into.seen.has(row.pc)) return;
  const rings = parseWkt(row.wkt);
  const house = rings ? toTileHouse(row.pc, rings) : null;
  if (!house) return;
  into.seen.add(row.pc);
  into.houses.push(house);
  into.perWard[ward.slug] = (into.perWard[ward.slug] ?? 0) + 1;
}

/** Each zoom-16 tile with the houses that touch it, encoded. */
export function tilesFor(houses: TileHouse[]): TileIn[] {
  const byTile = new Map<string, { x: number; y: number; houses: TileHouse[] }>();
  for (const h of houses)
    for (const t of tilesOf(h)) {
      const k = `${t.x}/${t.y}`;
      const cur = byTile.get(k) ?? { x: t.x, y: t.y, houses: [] };
      cur.houses.push(h);
      byTile.set(k, cur);
    }
  return [...byTile.values()].map((t) => ({
    z: HOUSE_ZOOM,
    x: t.x,
    y: t.y,
    data: encodeTile(t.x, t.y, t.houses),
  }));
}

export function countsFile(area: MapArea, found: Collected, built: string): HouseCounts {
  const wards = Object.fromEntries(
    Object.entries(found.perWard).sort(([a], [b]) => a.localeCompare(b)),
  );
  return {
    area: area.key,
    source: SOURCE,
    minConfidence: MIN_CONFIDENCE,
    built,
    total: found.houses.length,
    wards,
  };
}

/** What stops a build: a ward with no houses, or a file the host won't serve. */
export function problems(
  wards: WardShape[],
  perWard: Record<string, number>,
  bytes: number,
): string[] {
  const out = wards.filter((w) => !perWard[w.slug]).map((w) => `No houses in ${w.slug}.`);
  if (bytes > MAX_FILE_BYTES)
    out.push(
      `The file is ${(bytes / 1024 / 1024).toFixed(1)} MiB, over the 25 MiB a static file may be.`,
    );
  return out;
}
```

```ts
// (src/lib/map-areas.ts), from Google Open Buildings v3 (CC BY 4.0), as one
// PMTiles file per area and the number of houses in each ward.

import { createReadStream, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { createInterface } from "node:readline";
import { createGunzip, gzipSync } from "node:zlib";

import { inBox, wardShapes, type Box } from "@/lib/geo";
import {
  collect,
  countsFile,
  CSV_HEADER,
  emptyCollected,

  parseRow,

import { MAP_AREAS } from "@/lib/map-areas";
import { writeArchive } from "@/lib/pmtiles";

const src = process.argv[2];
if (!src) {
  console.error("Usage: npx tsx --tsconfig tsconfig.json scripts/geo/house-tiles.ts <183_buildings.csv.gz>");
  process.exit(1);
}

const areas = MAP_AREAS.map((area) => {
  const [west, south, east, north] = area.bounds;
  const box: Box = { west, south, east, north };
  const wards = wardShapes(JSON.parse(readFileSync(`public${area.wards}`, "utf8")));
  return { area, box, wards, found: emptyCollected() };
});

const lines = createInterface({ input: createReadStream(src).pipe(createGunzip()), crlfDelay: Infinity });
let header = true;
let rows = 0;
for await (const line of lines) {
  if (header) {
    header = false;
    if (line.trim() !== CSV_HEADER) {
      console.error(`These aren't Open Buildings v3 columns: ${line}`);
      process.exit(1);
    }
    continue;
  }
  rows += 1;
  if (rows % 5_000_000 === 0) console.log(`${rows / 1_000_000} million rows read…`);
  const p = quickPosition(line);
  if (!p) continue;
  for (const a of areas) {
    if (!inBox(p, a.box)) continue;
    const row = parseRow(line);
    if (row) collect(a.wards, a.box, row, a.found);
  }
}

const built = new Date().toISOString().slice(0, 10);

  const tiles = tilesFor(a.found.houses);
  const [w, s, e, n] = a.area.bounds;
  const file = writeArchive(
    tiles,
    {
      minZoom: HOUSE_ZOOM,
      maxZoom: HOUSE_ZOOM,
      bounds: a.area.bounds,
      center: [(w + e) / 2, (s + n) / 2, HOUSE_ZOOM],
      metadata: {
        name: `Houses: ${a.area.name}`,
        attribution: SOURCE,
        vector_layers: [{ id: LAYER, fields: { pc: "String" }, minzoom: HOUSE_ZOOM, maxzoom: HOUSE_ZOOM }],
      },
    },
    gz,
  );
  const counts = countsFile(a.area, a.found, built);
  console.log(
    `\n${a.area.name}: ${fmt(counts.total)} houses in ${fmt(tiles.length)} tiles, ` +
      `${(file.length / 1024 / 1024).toFixed(1)} MiB; ${fmt(a.found.lowConfidence)} below confidence ${MIN_CONFIDENCE}`,
  );
  for (const [slug, count] of Object.entries(counts.wards).sort((x, y) => y[1] - x[1]))
    console.log(`  ${slug.padEnd(32)} ${fmt(count)}`);

    stop = true;
  }
  outputs.push({
    path: `public${a.area.houses}`,

    countsPath: `public${a.area.counts}`,

}
if (stop) process.exit(1);

for (const o of outputs) {
  writeFileSync(o.path, o.file);
  writeFileSync(o.countsPath, o.counts);

}
```

```sql
-- repeat is also a visit already on a house, and a visit with a house is
-- counted against it.
create or replace function public.record_door(
  _client_id      uuid,
  _person_id      uuid,
  _new            jsonb,
  _outcome        text,
  _support        integer,
  _issue          text,
  _consent        jsonb,
  _consent_source text,
  _visited_at     timestamptz,
  _place          jsonb default null
)
returns jsonb
language plpgsql
security invoker
set search_path = public
as $$
declare
  _pid      uuid := _person_id;
  _at       timestamptz;
  _phone    text;
  _created  boolean := false;
  _kind     text;
  _opted    boolean;
  _sms      boolean := coalesce((_consent ->> 'sms')::boolean, false);
  _wa       boolean := coalesce((_consent ->> 'whatsapp')::boolean, false);
  _call     boolean := coalesce((_consent ->> 'call')::boolean, false);
  _channels text;
  _lat      double precision;
  _lng      double precision;
  _acc      real;
  _bld      text;
begin
  if _client_id is null then
    raise exception 'Each visit needs its own id.' using errcode = 'P0001';
  end if;
  -- Two syncs of the same visit at once (open tabs share the phone's queue):
  -- the second waits here for the first, then finds the visit on record.
  perform pg_advisory_xact_lock(hashtextextended(_client_id::text, 0));
  -- A retried sync: the visit is already on record.
  if exists (select 1 from public.person_events where client_id = _client_id)
     or exists (select 1 from public.house_visits where client_id = _client_id) then
    return jsonb_build_object('repeat', true);
  end if;

  if _outcome is null or _outcome not in ('spoke', 'not_home', 'refused') then
    raise exception 'Unknown outcome.' using errcode = 'P0001';
  end if;
  if _support is not null and _support not between 1 and 5 then
    raise exception 'Support is 1 to 5.' using errcode = 'P0001';
  end if;
  if (_sms or _wa or _call) and coalesce(btrim(_consent_source), '') = '' then
    raise exception 'Say how they agreed to be contacted.' using errcode = 'P0001';
  end if;

  -- The time the door was knocked, kept honest: not in the future, and not
  -- older than a week (a phone that was offline that long should say so).
  _at := least(now(), greatest(coalesce(_visited_at, now()), now() - interval '7 days'));

  -- Where the door was. A bad or vague fix is dropped, never an error.
  if jsonb_typeof(_place) = 'object' then
    if jsonb_typeof(_place -> 'lat') = 'number' and jsonb_typeof(_place -> 'lng') = 'number' then
      _lat := (_place ->> 'lat')::double precision;
      _lng := (_place ->> 'lng')::double precision;
      -- Outside Kenya is a broken fix, not a place.
      if _lat not between -5 and 5.5 or _lng not between 33.5 and 42.5 then
        _lat := null;
        _lng := null;
      end if;
    end if;
    if jsonb_typeof(_place -> 'accuracy') = 'number' then
      _acc := least(greatest((_place ->> 'accuracy')::real, 0), 100000);
      -- Wider than a few streets: too vague to pin anyone's home.
      if _acc > 250 then
        _lat := null;
        _lng := null;
      end if;
    end if;
    _bld := nullif(btrim(_place ->> 'buildingId'), '');
    if _bld is not null and _bld !~ '^[0-9A-Z+]{4,24}$' then
      _bld := null;
    end if;
  end if;

  if _pid is null then
    -- Someone met at the door. A number already on file means we know them:
    -- the visit goes on their record and only blanks are filled.
    _phone := _new ->> 'phone';
    if _phone is null or _phone !~ '^\+254[17][0-9]{8}$' then
      raise exception 'Use a Kenyan mobile number like 0712 345 678.' using errcode = 'P0001';
    end if;
    if coalesce(btrim(_new ->> 'name'), '') = '' then
      raise exception 'Add their name.' using errcode = 'P0001';
    end if;
    if _outcome <> 'spoke' then
      raise exception 'A new person is someone you spoke to.' using errcode = 'P0001';
    end if;

    select id into _pid from public.people where phone = _phone;
    if found then
      update public.people
         set full_name = coalesce(full_name, btrim(_new ->> 'name')),
             ward_id   = coalesce(ward_id, nullif(_new ->> 'ward_id', '')::uuid),
             segment   = coalesce(segment, nullif(btrim(_new ->> 'segment'), ''))
       where id = _pid;
    else
      insert into public.people (phone, full_name, ward_id, segment, language, source)
      values (_phone, btrim(_new ->> 'name'), nullif(_new ->> 'ward_id', '')::uuid,
              nullif(btrim(_new ->> 'segment'), ''), coalesce(nullif(_new ->> 'language', ''), 'sw'), 'door')
      returning id into _pid;
      _created := true;
      insert into public.person_events (person_id, kind, channel, detail, actor, created_at)
      values (_pid, 'added', 'door', 'Signed up at the door', auth.uid(), _at);
    end if;
  end if;

  select opted_out into _opted from public.people where id = _pid;
  if not found then
    raise exception 'That person is not on file, or you cannot see them.' using errcode = 'P0001';
  end if;

  _kind := case _outcome when 'spoke' then 'door_spoke'
                         when 'not_home' then 'door_not_home'
                         else 'door_refused' end;

  insert into public.person_events
    (person_id, kind, channel, detail, actor, created_at, client_id, lat, lng, accuracy_m, building_id)
  values (_pid, _kind, 'door',
          case when _outcome = 'spoke' then nullif(left(btrim(_issue), 120), '') end,
          auth.uid(), _at, _client_id, _lat, _lng, _acc, _bld);

  -- The house, too: every door knocked at a house is counted against it, with
  -- the ward of the person who answered (part 3 adds doors with no person).
  if _bld is not null then
    insert into public.house_visits
      (client_id, pc, ward_id, person_id, outcome, support, issue, actor, visited_at, lat, lng, accuracy_m)
    select _client_id, _bld, p.ward_id, _pid, _outcome,
           case when _outcome = 'spoke' then _support end,
           case when _outcome = 'spoke' then nullif(left(btrim(_issue), 120), '') end,
           auth.uid(), _at, _lat, _lng, _acc
      from public.people p
     where p.id = _pid
    on conflict (campaign_id, client_id) do nothing;
  end if;

  -- Pin the household: the door is their home. A later visit moves the pin;
  -- an earlier one synced late does not. A bare GPS point never replaces a
  -- building someone confirmed.
  if _bld is not null or _lat is not null then
    update public.people
       set building_id = coalesce(_bld, building_id),
           lat         = coalesce(_lat, lat),
           lng         = coalesce(_lng, lng),
           placed_at   = _at
     where id = _pid
       and (placed_at is null or placed_at <= _at)
       and (_bld is not null or building_id is null);
  end if;

  -- Speaking to someone, or being turned away, is contact; an empty house is not.
  if _outcome in ('spoke', 'refused') then
    update public.people
       set last_contacted_at = greatest(coalesce(last_contacted_at, _at), _at),
           -- The 1-5 door scale as a 0-100 score. Mirrors SUPPORT_SCORE in
           -- src/lib/people.ts: change both together.
           support_score = case when _outcome = 'spoke' and _support is not null
                                then (array[10, 30, 50, 75, 95])[_support]
                                else support_score end
     where id = _pid;
  end if;

  -- Consent given at the door, never over the top of a STOP.
  if (_sms or _wa or _call) and not coalesce(_opted, false) and _outcome = 'spoke' then
    update public.people
       set consent_sms      = consent_sms or _sms,
           consent_whatsapp = consent_whatsapp or _wa,
           consent_call     = consent_call or _call
     where id = _pid;
    _channels := concat_ws(', ',
      case when _sms then 'SMS' end, case when _wa then 'WhatsApp' end, case when _call then 'calls' end);
    insert into public.person_events (person_id, kind, channel, detail, actor, created_at)
    values (_pid, 'consent_given', 'door',
            left(format('Agreed to %s: %s', _channels, btrim(_consent_source)), 500), auth.uid(), _at);
  end if;

  return jsonb_build_object('repeat', false, 'person_id', _pid, 'created', _created,
                            'consent_blocked', (_sms or _wa or _call) and coalesce(_opted, false));
end;
$$;

-- 4. Doors per ward, from each house's latest visit in 30 days, and the visits
-- of the last seven days. Runs as the caller, so an agent counts their own.
create or replace function public.house_doors()
returns table (
  ward_id      uuid,
  knocked      integer,
  rated        integer,
  supporters   integer,
  doors_week   integer,
  agents_today uuid[]
)
language sql
stable
security invoker
set search_path = public
as $$
  with latest as (
    select distinct on (v.pc) v.pc, v.ward_id, v.outcome, v.support
      from public.house_visits v
     where v.visited_at > now() - interval '30 days'
     order by v.pc, v.visited_at desc
  ),
  per_ward as (
    select l.ward_id,
           count(*)::integer as knocked,
           (count(*) filter (where l.outcome = 'spoke' and l.support is not null))::integer as rated,
           (count(*) filter (where l.outcome = 'spoke' and l.support >= 4))::integer as supporters
      from latest l
     group by l.ward_id
  ),
  week as (
    select v.ward_id,
           count(*)::integer as doors_week,
           coalesce(array_agg(distinct v.actor) filter (
             where v.actor is not null
               and v.visited_at >= date_trunc('day', now() at time zone 'Africa/Nairobi') at time zone 'Africa/Nairobi'
           ), '{}') as agents_today
      from public.house_visits v
     where v.visited_at > now() - interval '7 days'
     group by v.ward_id
  )
  select coalesce(p.ward_id, w.ward_id),
         coalesce(p.knocked, 0), coalesce(p.rated, 0), coalesce(p.supporters, 0),
         coalesce(w.doors_week, 0), coalesce(w.agents_today, '{}')
    from per_ward p
    full join week w on w.ward_id = p.ward_id
$$;
```

```ts
// outcome, or the score, of its latest visit in 30 days; a ward is shaded by
// the share of its houses knocked, or by the supporters among its doors that
// gave a score. "Doors first" ranks wards by houses not yet knocked. Nothing
// is guessed: no data is grey, and the legend says so. Pure.

import { BAND_COLOUR } from "@/lib/wardmap";

export type Outcome = "spoke" | "not_home" | "refused";
export type Colour = "doors" | "support" | "vote";

/** A ward's doors: each house's latest visit in 30 days, and the visits of this week. */
export type WardDoors = {
  wardId: string;
  knocked: number;
  rated: number;
  supporters: number;
  doorsWeek: number;
  agentsToday: string[];

/** A house's latest visit in 30 days. */
export type HouseState = { pc: string; at: string; outcome: Outcome; support: number | null };

/** One visit at a house, for its card. */
export type HouseVisit = {
  at: string;
  agent: string | null;
  outcome: Outcome;
  support: number | null;
  issue: string | null;
  person: { id: string; name: string } | null;

/** A ward with this share of its houses knocked in 30 days is shaded full green. */
export const DOORS_FULL = 0.4;
export const NO_DATA = "hsl(0, 0%, 80%)";
export const NO_SCORE = "hsl(150, 6%, 70%)";
export const PLAIN = "hsl(0, 0%, 100%)";
/** An outline at least this big is often several homes: a block of flats, a plot of rooms. */
export const BLOCK_M2 = 200;

export const OUTCOME_LABEL: Record<Outcome, string> = {
  spoke: "Spoke",
  not_home: "Not home",
  refused: "Refused",
};

export const OUTCOME_COLOUR: Record<Outcome, string> = {
  spoke: "hsl(142, 62%, 40%)",
  not_home: "hsl(200, 85%, 62%)",
  refused: "hsl(0, 72%, 55%)",

const RED = [0, 72, 52];
const AMBER = [40, 92, 52];
const GREEN = [142, 62, 40];

/** Red at 0, amber at 0.5, green at 1; clamped, and NaN reads as 0. */
export function scaleColour(t: number): string {
  const x = Number.isNaN(t) ? 0 : Math.min(Math.max(t, 0), 1);
  const [from, to, u] = x <= 0.5 ? [RED, AMBER, x / 0.5] : [AMBER, GREEN, (x - 0.5) / 0.5];
  const [h, s, l] = from.map((v, i) => Math.round(v + (to[i]! - v) * u));
  return `hsl(${h}, ${s}%, ${l}%)`;
}

/** A house's fill for the colour on show; null for the 2022 vote, which shades wards only. */
export function houseColour(colour: Colour, h: HouseState): string | null {
  if (colour === "doors") return OUTCOME_COLOUR[h.outcome];
  if (colour === "support") {
    const s = h.support;
    return s !== null && s >= 1 && s <= 5 ? BAND_COLOUR[s as 1 | 2 | 3 | 4 | 5] : NO_SCORE;
  }
  return null;
}

/** A ward's fill: the share of its houses knocked, or of its scored doors that support us. */
export function wardShade(colour: Colour, houses: number, d: WardDoors | undefined): string {
  if (colour === "doors")
    return houses > 0 ? scaleColour((d?.knocked ?? 0) / houses / DOORS_FULL) : NO_DATA;
  if (colour === "support") return d && d.rated > 0 ? scaleColour(d.supporters / d.rated) : NO_DATA;
  return NO_DATA;
}

export type WardRef = { id: string; slug: string; name: string };
export type DoorsFirstRow = {
  wardId: string;
  slug: string;
  name: string;
  houses: number;
  knocked: number;
  notKnocked: number;
};

/** The wards with the most houses not knocked in 30 days; a ward with no house count is left out. */
export function doorsFirst(
  wards: WardRef[],
  houses: Record<string, number>,
  doors: WardDoors[],
  max = 6,
): DoorsFirstRow[] {
  const byWard = new Map(doors.map((d) => [d.wardId, d]));
  return wards
    .filter((w) => (houses[w.slug] ?? 0) > 0)
    .map((w) => {
      const total = houses[w.slug]!;
      const knocked = Math.min(byWard.get(w.id)?.knocked ?? 0, total);
      return {
        wardId: w.id,
        slug: w.slug,
        name: w.name,
        houses: total,
        knocked,
        notKnocked: total - knocked,
      };
    })
    .sort((a, b) => b.notKnocked - a.notKnocked || a.name.localeCompare(b.name))
    .slice(0, max);
}

export type DoorTotals = {
  houses: number;
  knocked: number;
  rated: number;
  supporters: number;
  doorsWeek: number;
  agentsToday: number;
};

/** The doors across some wards; an agent out in two of them counts once. */
export function doorTotals(
  wards: { id: string; slug: string }[],
  houses: Record<string, number>,
  doors: WardDoors[],
): DoorTotals {
  const ids = new Set(wards.map((w) => w.id));
  const inside = doors.filter((d) => ids.has(d.wardId));
  const sum = (f: (d: WardDoors) => number) => inside.reduce((t, d) => t + f(d), 0);
  return {
    houses: wards.reduce((t, w) => t + (houses[w.slug] ?? 0), 0),
    knocked: sum((d) => d.knocked),
    rated: sum((d) => d.rated),
    supporters: sum((d) => d.supporters),
    doorsWeek: sum((d) => d.doorsWeek),
    agentsToday: new Set(inside.flatMap((d) => d.agentsToday)).size,
  };
}

export const isOutcome = (v: unknown): v is Outcome =>
  v === "spoke" || v === "not_home" || v === "refused";

const count = (v: unknown): number | null =>
  typeof v === "number" && Number.isInteger(v) && v >= 0 ? v : null;

/** house_doors() rows; a row without a ward or with a bad count is left out. */
export function toWardDoors(rows: unknown): WardDoors[] {
  if (!Array.isArray(rows)) return [];
  const out: WardDoors[] = [];
  for (const r of rows as Record<string, unknown>[]) {
    const knocked = count(r["knocked"]);
    const rated = count(r["rated"]);
    const supporters = count(r["supporters"]);
    const doorsWeek = count(r["doors_week"]);
    if (typeof r["ward_id"] !== "string" || knocked === null || rated === null) continue;
    if (supporters === null || doorsWeek === null) continue;
    const agents = Array.isArray(r["agents_today"]) ? r["agents_today"] : [];
    out.push({
      wardId: r["ward_id"],
      knocked,
      rated,
      supporters,
      doorsWeek,
      agentsToday: agents.filter((a): a is string => typeof a === "string"),
    });
  }
  return out;
}

/** ward_houses() rows; a row without a house, a time or a known outcome is left out. */
export function toHouseStates(rows: unknown): HouseState[] {
  if (!Array.isArray(rows)) return [];
  const out: HouseState[] = [];
  for (const r of rows as Record<string, unknown>[]) {
    const s = r["support"];
    if (typeof r["pc"] !== "string" || typeof r["visited_at"] !== "string") continue;
    if (!isOutcome(r["outcome"])) continue;
    out.push({
      pc: r["pc"],
      at: r["visited_at"],
      outcome: r["outcome"],
      support: typeof s === "number" && s >= 1 && s <= 5 ? s : null,
    });
  }
  return out;
}
```

```ts
  const people = [...new Set(rows.map((r) => r.person_id).filter((p): p is string => Boolean(p)))];

      ? sb.from("profiles").select("user_id, full_name").in("user_id", actors)
      : { data: [] },
    people.length ? sb.from("people").select("id, full_name").in("id", people) : { data: [] },
  ])) as [
    { data: { user_id: string; full_name: string | null }[] | null },
    { data: { id: string; full_name: string | null }[] | null },
  ];
  const agentName = new Map(
    (profiles.data ?? []).map((p) => [p.user_id, p.full_name?.trim() || null]),
  );
  const personName = new Map((persons.data ?? []).map((p) => [p.id, p.full_name?.trim() || null]));
  return rows.map((r) => ({
    at: r.visited_at,
    agent: (r.actor && agentName.get(r.actor)) || null,
    outcome: r.outcome as HouseVisit["outcome"],
    support: typeof r.support === "number" ? r.support : null,
    issue: r.issue ?? null,
    person: r.person_id
      ? { id: r.person_id, name: personName.get(r.person_id) ?? "No name on file" }
      : null,
  }));
}
```

```ts
  | { kind: "ward"; slug: string; label: string; sub: string }
  | { kind: "constituency"; name: string; label: string; sub: string }

type SearchPerson = {
  id: string;
  name: string;
  phone: string;
  ward: string | null;
  house: string | null;

const fold = (s: string) =>
  s
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, " ")
    .trim();

/**
 * Wards and constituencies by name, and people by name, or by their number
 * when four or more digits are typed. At most `max` of each kind.
 */
export function searchHits(
  q: string,
  wards: SearchWard[],
  people: SearchPerson[],
  top: Top,
  max = 5,
): SearchHit[] {
  const needle = fold(q);
  if (!needle) return [];
  const digits = q.replace(/\D/g, "");
  // Typed the local way (0733…) or the international way (254733…), numbers are kept +254….
  const local = digits.replace(/^(?:254|0)/, "");
  const out: SearchHit[] = [];
  out.push(
    ...wards
      .filter((w) => fold(w.name).includes(needle))
      .slice(0, max)
      .map((w) => ({
        kind: "ward" as const,
        slug: w.slug,
        label: `${w.name} ward`,
        sub: top === "constituency" ? "Ward" : w.constituency,
      })),
  );
  if (top === "county") {
    const names = [...new Set(wards.map((w) => w.constituency))].sort();
    out.push(
      ...names
        .filter((n) => fold(n).includes(needle))
        .slice(0, max)
        .map((n) => ({ kind: "constituency" as const, name: n, label: n, sub: "Constituency" })),
    );
  }
  const slugOf = new Map(wards.map((w) => [w.name, w.slug]));
  out.push(
    ...people
      .filter((p) =>
        digits.length >= 4
          ? p.phone.replace(/\D/g, "").includes(local)
          : fold(p.name).includes(needle),
      )
      .slice(0, max)
      .map((p) => ({
        kind: "person" as const,
        id: p.id,
        label: p.name,
        sub: p.ward ? `${p.ward} ward` : "No ward on file",
        house: p.house,
        wardSlug: p.ward ? (slugOf.get(p.ward) ?? null) : null,
      })),
  );
  return out;
}

/** MapTiler's search for places and streets inside the map area; null without a key or for under 3 letters. */
export function geocodeUrl(
  q: string,
  key: string | null,
  bounds: [number, number, number, number],
): string | null {
  const text = q.trim();
  if (!key || text.length < 3) return null;
  const params = new URLSearchParams({
    key,
    bbox: bounds.join(","),
    country: "ke",
    limit: "5",
  });
  return `https://api.maptiler.com/geocoding/${encodeURIComponent(text)}.json?${params.toString()}`;
}

/** Places from a MapTiler search reply; anything without a name and a centre is left out. */
export function placeHits(json: unknown): SearchHit[] {
  const features = (json as { features?: unknown } | null)?.features;
  if (!Array.isArray(features)) return [];
  const out: SearchHit[] = [];
  for (const f of features as Record<string, unknown>[]) {
    const c = f["center"];
    const label = typeof f["text"] === "string" ? f["text"] : null;
    if (!label || !Array.isArray(c) || typeof c[0] !== "number" || typeof c[1] !== "number")
      continue;
    const full = typeof f["place_name"] === "string" ? f["place_name"] : "";
    out.push({
      kind: "place",
      label,
      sub: full.startsWith(`${label}, `) ? full.slice(label.length + 2) : full || "Place",
      center: [c[0], c[1]],
    });
  }
  return out;
}
```

```ts
// The browser's reader for a house file (public/tiles/houses-<id>.pmtiles):
// the header and directory once, then one tile per request, by HTTP range.
// Each file is opened once a session; an open that fails (no signal) is
// forgotten, so the next read tries again.

import type { Building } from "@/lib/geo";
import { decodeTile, HOUSE_ZOOM } from "@/lib/house-tiles";
import type { MapArea } from "@/lib/map-areas";
import { gunzip, openArchive, type Archive } from "@/lib/pmtiles";

type Fetch = (url: string, init?: RequestInit) => Promise<Response>;

const archives = new Map<string, Promise<Archive>>();

/** length bytes of url from offset. A host that ignores the range sends the whole file, which is cut. */
export async function readRange(
  url: string,
  offset: number,
  length: number,
  fetcher: Fetch = fetch,
): Promise<Uint8Array> {
  const res = await fetcher(url, {
    headers: { Range: `bytes=${offset}-${offset + length - 1}` },
  });
  if (!res.ok) throw new Error(`Could not read ${url} (${res.status}).`);
  const bytes = new Uint8Array(await res.arrayBuffer());
  return res.status === 206 ? bytes : bytes.subarray(offset, offset + length);
}

/** The house file at url, opened once a session. */
export function houseArchive(url: string, fetcher: Fetch = fetch): Promise<Archive> {
  let opened = archives.get(url);
  if (!opened) {
    opened = openArchive((o, l) => readRange(url, o, l, fetcher), gunzip);
    archives.set(url, opened);
    opened.catch(() => archives.delete(url));
  }
  return opened;
}

/** The houses in one zoom-16 tile of an area's house file; none where the file has no tile. */
export async function housesInTile(
  area: MapArea,
  x: number,
  y: number,
  fetcher: Fetch = fetch,
): Promise<Building[]> {
  const archive = await houseArchive(area.houses, fetcher);
  const bytes = await archive.getTile(HOUSE_ZOOM, x, y);
  return bytes ? decodeTile(x, y, bytes) : [];
}
```

```ts
// The houses within reach of the phone: the zoom-16 tiles of the area's house
// file around the GPS fix. Each tile is read while there is signal and kept
// for the session, so a street walked into a dead zone still finds its houses.

import { useQueries, type UseQueryResult } from "@tanstack/react-query";

import { inBox, type Building, type LngLat } from "@/lib/geo";
import { housesInTile } from "@/lib/house-source";
import { mergeHouses, tilesAround } from "@/lib/house-tiles";
import type { MapArea } from "@/lib/map-areas";

/** The 80 m picker, plus room for a vague fix. */
const AROUND_M = 120;

export type HouseStatus = "none" | "loading" | "ready";

/**
 * Whether the houses around the phone are known: none without a map area or
 * outside it, loading until there is a fix and a first tile, else ready.
 */
export function houseStatus(
  area: MapArea | null,
  fix: LngLat | null,
  pending: boolean,
  count: number,
): HouseStatus {
  if (!area) return "none";
  if (!fix) return "loading";
  const [west, south, east, north] = area.bounds;
  if (!inBox(fix, { west, south, east, north })) return "none";
  if (pending && count === 0) return "loading";
  return "ready";
}

// Outside the hook, so React Query keeps the merged list while no tile changes.
const combine = (results: UseQueryResult<Building[]>[]) => ({
  buildings: mergeHouses(results.map((r) => r.data ?? [])),
  pending: results.some((r) => r.isPending),
});

export function useHousesAround(
  area: MapArea | null,
  fix: LngLat | null,
): { buildings: Building[]; status: HouseStatus } {
  const inside = houseStatus(area, fix, false, 0) === "ready";
  const tiles = inside && fix ? tilesAround(fix, AROUND_M) : [];
  const { buildings, pending } = useQueries({
    queries: tiles.map((t) => ({
      queryKey: ["house-tile", area?.id, t.x, t.y],
      queryFn: () => housesInTile(area!, t.x, t.y),
      staleTime: Infinity,
      gcTime: Infinity,
      retry: 1,
    })),
    combine,
  });
  return { buildings, status: houseStatus(area, fix, pending, buildings.length) };
}
```

How it behaves:
- One map for every level: zoom 8 to 20 (AGENTS.md: MapLibre's own pan, wheel and pinch, bounded), bounds the area's plus a quarter on each side, no rotation.
- Houses: the vector source `gw-houses` reads `houses://<area id>/{z}/{x}/{y}`, a protocol registered once that returns a tile of the area's house file through `houseArchive` (an empty tile where there is none). Zoom 16 tiles only, stretched to 20; `promoteId: "pc"`, so a house's colour is feature state by plus code. The basemap's own buildings (OpenMapTiles' `building` layer) are hidden: our houses are the buildings.
- Wards: filled by `wardFill` below zoom 16, outlined always (the ward on show in the accent colour); at street level the other wards are dimmed. Ward names show from zoom 10.5 (a county's map; all zooms for a constituency's) to 16; a county's constituency names show below 11 and can be clicked.
- A click goes one level down: a constituency name or a ward (`onPick`), at ward level eases to zoom 16.5 where clicked, at street level a house (`onHouse`, with its footprint) or nothing.
- The camera: a new `camera.seq` flies to `camera.target` (a box is fitted, then its zoom clamped to the target's range), marked `{ app: true }`; `moveend` ignores those and reports any other move as `onMoved(areaAt(...), level)`. `padding.bottom` keeps the phone's sheet (Task 13) out of the map's centre.

```tsx
const EMPTY = { type: "FeatureCollection" as const, features: [] };

function styleUrl(basemap: Basemap, key: string | null): string {
  if (!key) return OPENFREEMAP;
  const k = encodeURIComponent(key);
  return basemap === "satellite"
    ? `https://api.maptiler.com/maps/hybrid/style.json?key=${k}`
    : `https://api.maptiler.com/maps/streets-v2/style.json?key=${k}`;
}

let housesProtocol = false;

/** houses://<area id>/{z}/{x}/{y}: a tile of the area's house file, read by range request. */
function addHousesProtocol(ml: typeof import("maplibre-gl")): void {
  if (housesProtocol) return;
  housesProtocol = true;
  ml.addProtocol("houses", async (params) => {
    const m = /^houses:\/\/([a-z0-9-]+)\/(\d+)\/(\d+)\/(\d+)$/.exec(params.url);
    const area = m ? MAP_AREAS.find((a) => a.id === m[1]) : undefined;
    if (!m || !area) return { data: new ArrayBuffer(0) };
    const archive = await houseArchive(area.houses);
    const bytes = await archive.getTile(Number(m[2]), Number(m[3]), Number(m[4]));
    return { data: bytes ? bytes.slice().buffer : new ArrayBuffer(0) };
  });
}

/** Our layers go on top of whichever basemap is showing; re-added after every style change. */
function addOverlays(map: MlMap, basemap: Basemap, mapArea: MapArea): void {
  const light = basemap === "streets";
  const ink = "hsl(158, 15%, 10%)";
  const quiet = light ? "hsla(158, 15%, 10%, 0.45)" : "hsla(0, 0%, 100%, 0.6)";
  const accent = "hsl(15, 77%, 52%)";
  const text = light ? ink : "hsl(0, 0%, 100%)";
  const halo = light ? "hsl(0, 0%, 100%)" : ink;

  // Our houses are the buildings: the basemap's own (OpenMapTiles' "building" layer) go.
  for (const l of map.getStyle().layers ?? [])
    if ((l as { "source-layer"?: string })["source-layer"] === "building")
      map.setLayoutProperty(l.id, "visibility", "none");

  map.addSource("gw-wards", {
    type: "geojson",
    data: EMPTY,
    promoteId: "slug",
    attribution: "Wards: geoBoundaries (CC BY 4.0)",
  });
  map.addSource("gw-houses", {
    type: "vector",
    tiles: [`houses://${mapArea.id}/{z}/{x}/{y}`],
    minzoom: STREET_ZOOM,
    maxzoom: STREET_ZOOM,
    bounds: mapArea.bounds,
    promoteId: "pc",
    attribution: "Houses: Google Open Buildings v3 (CC BY 4.0)",
  });
  map.addSource("gw-constituencies", { type: "geojson", data: EMPTY });

  map.addLayer({
    id: "gw-wards-fill",
    type: "fill",
    source: "gw-wards",
    maxzoom: STREET_ZOOM,
    paint: {
      "fill-color": ["to-color", ["coalesce", ["feature-state", "fill"], "hsla(0, 0%, 0%, 0)"]],
      "fill-opacity": ["case", ["boolean", ["feature-state", "sel"], false], 0.3, 0.55],
    },
  });
  map.addLayer({
    id: "gw-houses-fill",
    type: "fill",
    source: "gw-houses",
    "source-layer": LAYER,
    minzoom: STREET_ZOOM,
    paint: {
      "fill-color": ["to-color", ["coalesce", ["feature-state", "col"], "hsl(0, 0%, 100%)"]],
      "fill-opacity": [
        "case",
        ["boolean", ["feature-state", "has"], false],
        0.8,
        light ? 0.35 : 0.18,
      ],
    },
  });
  map.addLayer({
    id: "gw-houses-line",
    type: "line",
    source: "gw-houses",
    "source-layer": LAYER,
    minzoom: STREET_ZOOM + 0.5,
    paint: {
      "line-color": [
        "case",
        ["boolean", ["feature-state", "focus"], false],
        accent,
        light ? "hsla(158, 15%, 10%, 0.55)" : "hsla(0, 0%, 100%, 0.7)",
      ],
      "line-width": ["case", ["boolean", ["feature-state", "focus"], false], 3, 0.7],
    },
  });
  // At street level, every ward but the one on show is dimmed.
  map.addLayer({
    id: "gw-wards-mask",
    type: "fill",
    source: "gw-wards",
    minzoom: STREET_ZOOM,
    filter: ["==", ["get", "slug"], NO_WARD],
    paint: { "fill-color": ink, "fill-opacity": 0.45 },
  });
  map.addLayer({
    id: "gw-wards-line",
    type: "line",
    source: "gw-wards",
    paint: {
      "line-color": ["case", ["boolean", ["feature-state", "sel"], false], accent, quiet],
      "line-width": ["case", ["boolean", ["feature-state", "sel"], false], 3, 1],

    id: "gw-wards-label",
    type: "symbol",

    maxzoom: STREET_ZOOM,
    layout: {
      "text-field": ["get", "name"],
      "text-font": ["Noto Sans Regular"],
      "text-size": 11,
      "text-max-width": 8,
    },
    paint: { "text-color": text, "text-halo-color": halo, "text-halo-width": 1.2 },
  });

    map.addLayer({
      id: "gw-constituency-label",
      type: "symbol",
      source: "gw-constituencies",
      maxzoom: CONSTITUENCY_ZOOM,

        "text-font": ["Noto Sans Regular"],
        "text-size": 13,
        "text-transform": "uppercase",
        "text-letter-spacing": 0.06,
        "text-max-width": 7,

function hasLayer(map: MlMap, id: string): boolean {
  try {
    return Boolean(map.getLayer(id));
  } catch {
    return false;
  }
}

/** A house's footprint from its drawn outline, in whole m². */
function footprint(f: MapGeoJSONFeature): number | null {
  const g = f.geometry;
  const polygons: Ring[][] =
    g.type === "Polygon"
      ? [g.coordinates as Ring[]]
      : g.type === "MultiPolygon"
        ? (g.coordinates as Ring[][])
        : [];
  const first = polygons[0];
  if (!first?.[0]) return null;
  const holes = first.slice(1).reduce((s, r) => s + ringAreaM2(r), 0);
  return Math.round(ringAreaM2(first[0]) - holes);
}

function withMargin([w, s, e, n]: [number, number, number, number]): LngLatBoundsLike {
  const dx = (e - w) * 0.25;
  const dy = (n - s) * 0.25;
  return [
    [w - dx, s - dy],
    [e + dx, n + dy],
  ];
}

/** The app moves the camera: flown, and marked so moveend doesn't report it as the person's move. */
function fly(map: MlMap, t: CameraTarget, duration = 800): void {
  if (t.kind === "point") {
    map.flyTo({ center: t.center, zoom: t.zoom, duration, essential: true }, { app: true });
    return;
  }
  const c = map.cameraForBounds(
    [
      [t.box.west, t.box.south],
      [t.box.east, t.box.north],
    ],
    { padding: 32 },
  );
  if (!c?.center || c.zoom === undefined) return;
  const zoom = Math.min(Math.max(c.zoom, t.minZoom), t.maxZoom);
  map.flyTo({ center: c.center, zoom, duration, essential: true }, { app: true });
}

export function VotersCanvas(props: Props) {
  const host = useRef<HTMLDivElement>(null);
  const mapRef = useRef<MlMap | null>(null);
  const latest = useRef(props);
  latest.current = props;
  // loaded: the first style is up; styleRev bumps after every style load so
  // data and states are put back on the new basemap.
  const [loaded, setLoaded] = useState(false);
  const [styleRev, setStyleRev] = useState(0);
  const [zoomLevel, setZoomLevel] = useState(MIN_ZOOM);
  const labels: LabelPoints = useMemo(
    () => constituencyLabels(props.shapes, props.wardInfo),
    [props.shapes, props.wardInfo],
  );

  useEffect(() => {
    let dead = false;
    let map: MlMap | null = null;
    void import("maplibre-gl").then((ml) => {
      if (dead || !host.current) return;
      ml.setWorkerUrl(maplibreWorker);
      addHousesProtocol(ml);
      const p = latest.current;
      const start =
        p.camera?.target ?? cameraFor({ area: p.area }, p.wardInfo, p.shapes, p.mapArea);
      map = new ml.Map({
        container: host.current,
        style: styleUrl(p.basemap, p.maptilerKey),
        ...(start.kind === "point"
          ? { center: start.center, zoom: start.zoom }
          : {
              bounds: [
                [start.box.west, start.box.south],
                [start.box.east, start.box.north],
              ] as LngLatBoundsLike,
              fitBoundsOptions: { padding: 32, maxZoom: start.maxZoom },
            }),
        maxBounds: withMargin(p.mapArea.bounds),
        attributionControl: { compact: true },
        dragRotate: false,
        pitchWithRotate: false,
        minZoom: MIN_ZOOM,
        maxZoom: MAX_ZOOM,
      });
      map.touchZoomRotate.disableRotation();
      map.addControl(new ml.ScaleControl({ maxWidth: 110, unit: "metric" }), "bottom-right");
      setZoomLevel(map.getZoom());
      map.on("style.load", () => {
        if (!map) return;
        addOverlays(map, latest.current.basemap, latest.current.mapArea);
        setStyleRev((r) => r + 1);
        setLoaded(true);
      });
      let level = levelFor(map.getZoom(), p.mapArea.top);
      map.on("zoom", () => {
        if (!map) return;
        const z = map.getZoom();
        setZoomLevel(z);
        const next = levelFor(z, latest.current.mapArea.top);
        if (next !== level) {
          level = next;
          latest.current.onLevel(next);
        }
      });
      map.on("moveend", (e) => {
        if (!map || (e as { app?: boolean }).app) return;
        const q = latest.current;
        const at = levelFor(map.getZoom(), q.mapArea.top);
        const c = map.getCenter();
        q.onMoved(areaAt(at, [c.lng, c.lat], q.shapes, q.wardInfo, q.mapArea.top), at);
      });
      map.on("error", (e) => {
        const status = (e.error as { status?: number } | undefined)?.status;
        if (status === 401 || status === 403) latest.current.onTilesRefused();
      });
      map.on("click", (e) => {
        if (!map) return;
        const q = latest.current;
        const at = levelFor(map.getZoom(), q.mapArea.top);
        if (at === "street") {
          const hit = hasLayer(map, "gw-houses-fill")
            ? map.queryRenderedFeatures(e.point, { layers: ["gw-houses-fill"] })[0]
            : undefined;
          const pc = hit ? String(hit.properties?.["pc"] ?? "") : "";
          q.onHouse(pc || null, hit && pc ? footprint(hit) : null);
          return;
        }
        if (at === "ward") {
          // The person's move: moveend says where it ended up.
          map.easeTo({ center: e.lngLat, zoom: STREET_ZOOM + 0.5, duration: 600 });
          return;
        }
        const label =
          at === "area" && hasLayer(map, "gw-constituency-label")
            ? map.queryRenderedFeatures(e.point, { layers: ["gw-constituency-label"] })[0]
            : undefined;
        const name = label ? String(label.properties?.["name"] ?? "") : "";
        if (name) {
          q.onPick({ level: "constituency", name });
          return;
        }
        const w = hasLayer(map, "gw-wards-fill")
          ? map.queryRenderedFeatures(e.point, { layers: ["gw-wards-fill"] })[0]
          : undefined;
        const slug = w ? String(w.properties?.["slug"] ?? "") : "";
        if (slug) q.onPick({ level: "ward", slug });
      });
      for (const layer of ["gw-houses-fill", "gw-wards-fill", "gw-constituency-label"]) {
        map.on("mouseenter", layer, () => {
          if (map) map.getCanvas().style.cursor = "pointer";
        });
        map.on("mouseleave", layer, () => {
          if (map) map.getCanvas().style.cursor = "";
        });
      }
      mapRef.current = map;
    });
    return () => {
      dead = true;
      map?.remove();
      mapRef.current = null;
    };
  }, []);

  // A different basemap: reload the style in full (a diff would skip style.load);
  // our layers are added back on style.load.
  useEffect(() => {
    const map = mapRef.current;
    if (!map) return;
    map.setStyle(styleUrl(props.basemap, props.maptilerKey), { diff: false });
  }, [props.basemap, props.maptilerKey]);

  useEffect(() => {
    const map = mapRef.current;
    if (!map || !styleRev) return;
    (map.getSource("gw-wards") as GeoJSONSource | undefined)?.setData(props.wards as never);
    (map.getSource("gw-constituencies") as GeoJSONSource | undefined)?.setData(labels as never);
  }, [styleRev, props.wards, labels]);

  const shownWard = props.area.level === "ward" ? props.area.slug : null;
  useEffect(() => {
    const map = mapRef.current;
    if (!map || !styleRev) return;
    for (const f of props.wards.features) {
      const slug = f.properties.slug;
      map.setFeatureState(
        { source: "gw-wards", id: slug },
        { fill: props.wardFill[slug] ?? "", sel: slug === shownWard },
      );
    }
    if (hasLayer(map, "gw-wards-mask"))
      map.setFilter("gw-wards-mask", ["!=", ["get", "slug"], shownWard ?? NO_WARD]);
  }, [styleRev, props.wards, props.wardFill, shownWard]);

  useEffect(() => {
    const map = mapRef.current;
    if (!map || !styleRev || !map.getSource("gw-houses")) return;
    const source = { source: "gw-houses", sourceLayer: LAYER };
    map.removeFeatureState(source);
    for (const [id, col] of props.houseColours)
      map.setFeatureState({ ...source, id }, { col, has: true });
    if (props.house) map.setFeatureState({ ...source, id: props.house }, { focus: true });
  }, [styleRev, props.houseColours, props.house]);

  useEffect(() => {
    const map = mapRef.current;
    if (!map || !loaded || !props.camera) return;
    fly(map, props.camera.target);
    // Only a new seq sends the camera again.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [loaded, props.camera?.seq]);

  useEffect(() => {
    mapRef.current?.setPadding({ top: 0, right: 0, left: 0, bottom: props.padding.bottom });
  }, [props.padding.bottom, loaded]);

  function zoom(by: number) {
    const map = mapRef.current;
    if (!map) return;
    map.easeTo({ zoom: Math.max(MIN_ZOOM, Math.min(MAX_ZOOM, map.getZoom() + by)), duration: 240 });
  }

  function fit() {
    const map = mapRef.current;
    if (!map) return;
    fly(map, cameraFor({ area: props.area }, props.wardInfo, props.shapes, props.mapArea), 600);
  }

  return (
    <div className="vmap">
      <div
        ref={host}
        className="vmap-canvas"
        aria-label={`Map of ${props.mapArea.name}: its wards, and every house from zoom 16`}
      />
      {!loaded && <div className="vmap-loading meta">Loading the map…</div>}
      {props.children}
      <div className="vglass vzoom" aria-label="Map zoom controls">
        <button
          type="button"
          aria-label="Zoom in"
          title="Zoom in"
          disabled={!loaded || zoomLevel >= MAX_ZOOM - 0.01}
          onClick={() => zoom(1)}
        >
          +
        </button>
        <button
          type="button"
          aria-label="Zoom out"
          title="Zoom out"
          disabled={!loaded || zoomLevel <= MIN_ZOOM + 0.01}
          onClick={() => zoom(-1)}
        >
          −
        </button>
        <button
          type="button"
          aria-label="Show the whole area on show"
          title="Show the whole area on show"
          onClick={fit}
        >
          <span aria-hidden="true">⌖</span>
        </button>
      </div>
      {props.maptilerKey && (
        <a
          className="vlogo"
          href="https://www.maptiler.com"
          target="_blank"
          rel="noopener noreferrer"
        >
          <img
            src="https://api.maptiler.com/resources/logo.svg"
            alt="MapTiler"
            width="67"
            height="20"
          />
        </a>
      )}
    </div>
  );
}
```
